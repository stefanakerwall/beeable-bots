Beeable – lägen och tillstånd

UI-lägen som animationer, och en tillståndsmaskin där varje övergång har en egen liten rörelse. Allt stannar på platsen. ← Bi-exempel

UI-lägen

Korta loopar för vanliga lägen i ett gränssnitt.

Tillstånd

Välj ett läge. Varje byte spelar en egen övergång – loggen visar vilken.

// Styr boten från din egen kod:
beeState.set('working');   // idle, thinking, working, busy, done, typing, loading
beeState.get();            // → 'working'
beeState.auto(true);       // vandrar mellan lägen
const off = beeState.on(e => console.log(e.from, '→', e.to));

Respekterar ”minska rörelse”: då visas stillbilder och lägen byts direkt.
